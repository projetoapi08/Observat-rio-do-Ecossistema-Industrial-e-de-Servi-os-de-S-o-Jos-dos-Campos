# PACER da equipe

[voltar ao índice da documentação](../../README.md) · [voltar ao README do projeto](../../../README.md)

O PACER é a avaliação de cada membro nos pilares da metodologia API: **P**roatividade, **A**utonomia, **C**olaboração e **E**ntrega de **R**esultados. Ele faz parte da entrega final do projeto.

## Situação

**A preencher.** As notas são dadas pela equipe no modelo oficial da disciplina. Esta pasta guarda o arquivo preenchido.

## Como preencher

1. Baixe o modelo oficial do PACER passado pelos professores.
2. Cada membro avalia os colegas e a si mesmo nos quatro pilares, como pede o modelo.
3. O Scrum Master junta as avaliações em um único arquivo.
4. Salve o arquivo nesta pasta com o nome `PACER_Equipe_Observatorio_SJC` (na extensão do modelo, por exemplo .xlsx) e, se possível, uma cópia em PDF.
5. Atualize a tabela abaixo e a linha "PACER preenchido" da seção [Entrega final](../../../README.md#entrega-final) do README.
