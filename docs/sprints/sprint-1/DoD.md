# Definition of Done (DoD) — proposta inicial

> Ajustar com a equipe na Sprint Planning e manter igual para todas as sprints (compromisso do Incremento, conforme o Guia do Scrum).

Um item do backlog só é considerado **pronto** quando:

- [ ] O código/notebook está versionado no GitHub, na pasta correta
- [ ] Os dados filtrados foram validados (conferência de contagem de registros para SJC)
- [ ] A visualização correspondente foi testada no Power BI sem erros
- [ ] A documentação relacionada foi atualizada (README, backlog ou relatório técnico)
- [ ] Foi revisado por pelo menos um outro membro da equipe
- [ ] Foi demonstrado funcionando na Sprint Review
