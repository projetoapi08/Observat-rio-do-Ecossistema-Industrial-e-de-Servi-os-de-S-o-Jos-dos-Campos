# Notebooks

Pasta para os notebooks do Google Colab usados no tratamento dos dados (ETL).

Sugestão de nomenclatura: `sprint-N_descricao.ipynb` (ex.: `sprint-1_etl-rais-sjc.ipynb`).

Cada notebook publicado no Colab deve ter o link também referenciado no relatório técnico da sprint correspondente, em `docs/sprints/sprint-N/`.
